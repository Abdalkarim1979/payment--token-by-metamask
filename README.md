
# Token Payment with MetaMask  

## 📖 Project Description  
**Token Payment with MetaMask** is a simple web application that enables users to make token payments directly through their **MetaMask wallet**. The app provides an intuitive interface to connect MetaMask, switch between multiple blockchain networks, and send tokens securely to any recipient address.  

---

## ✨ Features
- 🔗 **Connect MetaMask**: One‑click button to connect the user’s wallet.  
- 🌐 **Network Selection**: Supports multiple networks including Ethereum Mainnet, Binance Smart Chain, Polygon, Avalanche, Fantom, xDai, and Holesky.  
- 💸 **Token Payments**: Enter the token contract address, amount, and recipient address to execute payments.  
- 📊 **Connection Status**: Displays whether MetaMask is connected and shows the connected wallet address.  
- 🎨 **Modern UI**: Clean and responsive design with styled inputs, buttons, and forms.  

---

## 🛠️ Technologies Used
- **HTML5 / CSS3** for layout and styling  
- **JavaScript (web3.js)** for blockchain interaction  
- **MetaMask** for wallet connection and transaction execution
